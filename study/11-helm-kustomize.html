Helm, Kustomize, CRDs & Images

Packaging and extending Kubernetes: Helm charts, Kustomize overlays, CustomResourceDefinitions and operators, and building container images. Related lab: 12.

Helm

A chart is a package of templates plus values.yaml. A release is an installed instance of a chart, with numbered revisions.

helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update
helm search repo nginx
helm show values bitnami/nginx > values.yaml

helm install web bitnami/nginx -n apps --create-namespace --set replicaCount=3
helm install web bitnami/nginx -f values.yaml --version 18.1.0
helm upgrade --install web bitnami/nginx -n apps -f values.yaml --atomic --wait
helm list -A                       # -a to include failed/pending
helm status web -n apps
helm get values web -n apps        # user-supplied values
helm get manifest web -n apps      # what was applied
helm history web -n apps
helm rollback web 2 -n apps
helm uninstall web -n apps
helm template web ./mychart        # render locally
helm create mychart ; helm lint mychart

Value precedence: chart defaults < -f files (later files win) < --set.

Kustomize

Built into kubectl. Template-free: a base of plain YAML plus overlays that patch it.

app/
  base/
    deployment.yaml
    service.yaml
    kustomization.yaml
  overlays/
    prod/
      kustomization.yaml
      replicas-patch.yaml
# base/kustomization.yaml
resources:
  - deployment.yaml
  - service.yaml

# overlays/prod/kustomization.yaml
resources:
  - ../../base
namespace: prod
namePrefix: prod-
labels:
  - pairs: { env: prod }
    includeSelectors: true
images:
  - name: nginx
    newTag: "1.25"
replicas:
  - name: web
    count: 5
patches:
  - path: replicas-patch.yaml
configMapGenerator:
  - name: app-config
    literals: [MODE=prod]
kubectl kustomize overlays/prod      # print
kubectl apply -k overlays/prod       # apply
kubectl delete -k overlays/prod

CRDs and operators

  • A CustomResourceDefinition adds a new kind to the API (e.g. Certificate, Backup). It stores objects but does nothing by itself.
  • An operator is a controller that watches those objects and reconciles real resources. Usually installed with Helm or a manifest.
kubectl get crd
kubectl get crd certificates.cert-manager.io -o yaml
kubectl api-resources --api-group=cert-manager.io
kubectl explain certificate.spec
kubectl get certificates -A
apiVersion: apiextensions.k8s.io/v1
kind: CustomResourceDefinition
metadata: { name: backups.example.com }       # <plural>.<group>
spec:
  group: example.com
  scope: Namespaced
  names: { plural: backups, singular: backup, kind: Backup, shortNames: [bk] }
  versions:
    - name: v1
      served: true
      storage: true
      schema:
        openAPIV3Schema:
          type: object
          properties:
            spec:
              type: object
              properties:
                schedule: { type: string }

Container images

FROM nginx:1.25-alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
docker build -t web:1.0 .                     # or: podman build -t web:1.0 .
docker images
docker save web:1.0 -o /opt/web-1.0.tar      # lab 12: export to a tar file
docker load -i /opt/web-1.0.tar
docker tag web:1.0 registry.local/web:1.0 && docker push registry.local/web:1.0
sudo ctr -n k8s.io images import /opt/web-1.0.tar   # load into containerd on a node
sudo crictl images
DockerfileKubernetes field
ENTRYPOINTcommand
CMDargs
ENVenv
EXPOSEports[].containerPort (informational)
USERsecurityContext.runAsUser

Image pull policy: Always (default for :latest or no tag), IfNotPresent (default for other tags), Never (local images only).
