kubeadm, Upgrades & etcd Backup

Install a cluster, add nodes, upgrade one minor version, renew certificates and back up / restore etcd. These tasks are almost guaranteed on the CKA.

Node prerequisites

# kernel modules and sysctl
cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF
sudo modprobe overlay && sudo modprobe br_netfilter
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF
sudo sysctl --system
sudo swapoff -a                                    # and remove swap from /etc/fstab

# containerd with systemd cgroups
containerd config default | sudo tee /etc/containerd/config.toml
sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
sudo systemctl restart containerd

# packages (repo per minor version on pkgs.k8s.io)
sudo apt-get install -y kubelet kubeadm kubectl && sudo apt-mark hold kubelet kubeadm kubectl

Create the cluster

sudo kubeadm init --pod-network-cidr=10.244.0.0/16 \
  --apiserver-advertise-address=192.168.56.10 \
  --control-plane-endpoint=k8s-api.local          # needed for a future HA control plane
mkdir -p $HOME/.kube && sudo cp /etc/kubernetes/admin.conf $HOME/.kube/config && sudo chown $(id -u):$(id -g) $HOME/.kube/config
kubectl apply -f <cni-manifest.yaml>               # nodes stay NotReady until a CNI is installed

# on the control plane, print a join command (tokens live 24h)
kubeadm token create --print-join-command
# on each worker
sudo kubeadm join 192.168.56.10:6443 --token abc.def --discovery-token-ca-cert-hash sha256:...

Defaults: Service CIDR 10.96.0.0/12, DNS domain cluster.local. kubeadm reset undoes init/join on a node.

Upgrade one minor version

Rule: one minor at a time, control plane first, then workers one by one. kubeadm before kubelet.

Control-plane node

# 1. point apt at the new minor repo, then
sudo apt-mark unhold kubeadm && sudo apt-get update && sudo apt-get install -y kubeadm='1.35.1-*' && sudo apt-mark hold kubeadm
kubeadm version
sudo kubeadm upgrade plan
sudo kubeadm upgrade apply v1.35.1               # other control-plane nodes: sudo kubeadm upgrade node

# 2. kubelet and kubectl
kubectl drain cp1 --ignore-daemonsets
sudo apt-mark unhold kubelet kubectl && sudo apt-get install -y kubelet='1.35.1-*' kubectl='1.35.1-*' && sudo apt-mark hold kubelet kubectl
sudo systemctl daemon-reload && sudo systemctl restart kubelet
kubectl uncordon cp1

Each worker

kubectl drain w1 --ignore-daemonsets --delete-emptydir-data     # from the control plane
# on w1:
sudo apt-get install -y kubeadm='1.35.1-*'
sudo kubeadm upgrade node
sudo apt-get install -y kubelet='1.35.1-*' kubectl='1.35.1-*'
sudo systemctl daemon-reload && sudo systemctl restart kubelet
kubectl uncordon w1                                              # from the control plane
kubectl get nodes                                                # VERSION column

Version skew: kubelet may be up to three minors older than the API server, never newer. kubectl ±1 minor.

etcd backup and restore

Take the endpoints and certificate paths from /etc/kubernetes/manifests/etcd.yaml (--listen-client-urls, --cert-file, --key-file, --trusted-ca-file).

# backup
ETCDCTL_API=3 etcdctl --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt \
  --cert=/etc/kubernetes/pki/etcd/server.crt \
  --key=/etc/kubernetes/pki/etcd/server.key \
  snapshot save /opt/backup/etcd-snap.db
etcdutl snapshot status /opt/backup/etcd-snap.db --write-out=table

# restore (offline operation, no certificates needed)
etcdutl snapshot restore /opt/backup/etcd-snap.db --data-dir=/var/lib/etcd-restore
# older tools: ETCDCTL_API=3 etcdctl snapshot restore ... --data-dir=/var/lib/etcd-restore

# point etcd at the restored data
sudo vi /etc/kubernetes/manifests/etcd.yaml
#   volumes:
#   - hostPath: { path: /var/lib/etcd-restore, type: DirectoryOrCreate }
#     name: etcd-data
# the kubelet recreates the etcd Pod; the API server reconnects (give it a minute)
kubectl get pods -A
Common mistakes: forgetting the TLS flags on save, using http instead of https, changing --data-dir in the command line but not the hostPath (or the reverse), and leaving the restore directory owned by the wrong user.

Certificates

sudo kubeadm certs check-expiration
sudo kubeadm certs renew all          # then restart control-plane static Pods (move manifests out and back, or restart kubelet)
openssl x509 -in /etc/kubernetes/pki/apiserver.crt -noout -text | grep -A1 -E 'Not After|Alternative'

The cluster CA is valid for 10 years; leaf certificates for 1 year and are renewed by every kubeadm upgrade.

HA control plane (concepts)

  • Stacked etcd (etcd on each control-plane node) vs external etcd cluster.
  • A load balancer in front of the API servers; --control-plane-endpoint points at it.
  • Add control-plane nodes with kubeadm join ... --control-plane --certificate-key ... (key from kubeadm init phase upload-certs --upload-certs).
  • etcd needs an odd number of members (3 or 5) to keep quorum.
